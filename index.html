线境 · 使用说明

这是可迭代的功能预览版，不是生产级印前软件。所有图像与几何计算在浏览器本机执行。

从图片开始

粘贴 / 拖入图片 → 拖动参数实时预览 → 确认生成轮廓 → 用节点工具修形 → 切割合并 → 填色 → 导出文件。

关键操作

选择 / 节点V / N进入节点编辑双击图形增加 / 删除节点Ctrl 点击曲线 / Alt 点击节点群组 / 解组Ctrl G / Ctrl Shift G复制副本Ctrl D直线切割 / 剪断路径K / C钢笔结束 / 闭合Enter / 点击起点独立调整手柄Alt + 拖动手柄框选或多选拖动空白 / Shift撤销 / 重做Ctrl Z / Ctrl Shift Z连接端点 / 合并J / U平移 / 缩放空格拖动 / 滚轮保存项目 / 全选Ctrl S / Ctrl A

切割只作用于按下到松开之间的有限线段，不延伸到画板两端。必须贯穿闭合区域才会拆成独立色块；只划到内部不会自动补齐。剪断单条轮廓请用剪断工具。

保存与限制

用 .vstudio 保存可继续编辑的项目；SVG 导出保留路径、颜色和孔洞，不含参考图片。Ctrl S 保存到本地项目库；下载 .vstudio 可以备份和跨设备迁移。清除浏览器站点数据会清空项目库。切换未保存项目会提醒保存、放弃或取消。

当前是像素轮廓预览算法，不是 VTracer。几何运算先以 0.35 px 近似展开曲线，复杂稿件应检查。任意线围成区域的自动填色、原生 AI / CDR、CMYK / 专色、通用 SVG 导入尚未实现。

导出文件

只导出可见矢量对象，不包含参考原图。原图和完整编辑状态请用「下载项目」。

SVG · 矢量交换格式路径、曲线、填色、镂空和群组。可导入 Illustrator / CorelDRAW，再另存原生 AI / CDR；导入效果需检查。
PSD · 矢量形状图层（实验）纯色闭合形状、矢量蒙版和群组；RGB / 8 位。暂不支持描边、开放路径或专色，不会转成像素图层冒充。尚待 Photoshop 实机验证。

AI / CDR · 原生格式尚未实现直接写入；请使用 SVG 交换，不通过修改后缀冒充。
