线境 · 首版使用说明

这是可迭代的功能预览版，不是生产级印前软件。所有图像与几何计算在浏览器本机执行。

从图片开始

粘贴 / 拖入图片 → 拖动参数实时预览 → 确认生成轮廓 → 用节点工具修形 → 切割合并 → 填色 → 导出 SVG。

关键操作

选择 / 节点V / N增加节点A 或双击曲线直线切割 / 剪断路径K / C钢笔结束 / 闭合Enter / 点击起点独立调整手柄Alt + 拖动手柄框选或多选拖动空白 / Shift撤销 / 重做Ctrl Z / Ctrl Shift Z连接端点 / 合并J / U平移 / 缩放空格拖动 / 滚轮保存项目 / 全选Ctrl S / Ctrl A

切割只作用于按下到松开之间的有限线段，不延伸到画板两端。必须贯穿闭合区域才会拆成独立色块；只划到内部不会自动补齐。剪断单条轮廓请用剪断工具。

保存与限制

用 .vstudio 保存可继续编辑的项目；SVG 导出保留路径、颜色和孔洞，不含参考图片。浏览器草稿只是辅助，请主动保存项目文件。

当前是像素轮廓预览算法，不是 VTracer。几何运算先以 0.35 px 近似展开曲线，复杂稿件应检查。任意线围成区域的自动填色、PSD / AI / CDR、CMYK / 专色、通用 SVG 导入尚未实现。
