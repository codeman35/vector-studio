# v0.5.1：弧线光标与直接拖动线段

2026-09-24。基线：7ba7cbcea28393fb52fcd596c6ade6305c26f514 / v0.5.0。

## 功能与范围

节点编辑中，鼠标靠近当前对象两节点之间的线段时显示弧线与双向箭头光标，当前段蓝色高亮。可以向外拉、向内推，也可以在同一次拖动中跨过原位置。两端锚点和相邻线段保持不变，只调整本段两个控制手柄。直线可直接拉弯，不增加节点。

保留节点/手柄优先命中，内部/外部框选、Shift 强制追加框选、Ctrl 加点和 Alt 删点。超过 3 屏幕像素才变形，点击和返回起点不改几何；每次拖动一次撤销。Escape、指针取消和失焦恢复原手柄。

## 限制

相邻段保持不变，因此连接处可能变成尖角；不自动调整邻段来维持平滑。允许自由形变，可能产生自交。现有 AI/CDR、PSD 和曲线近似运算的限制不变。
