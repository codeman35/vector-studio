## 本地验证

Linux / Node.js 22 / Chromium / Playwright。

- 语法检查、构建通过，脚本 CSP 哈希重新生成。
- 可用单元测试子集 26 项通过（其中新增曲线 10 项）；完整远程测试保留在仓库，由 GitHub Actions 执行。不能把本地子集数量冒充完整套件。
- browser-trace-curves.py 通过，使用带 CSP 的真实单文件和 Blob Worker：控件可见、无图片禁用、二次／三次预览路径不同、最新参数覆盖旧任务、圆滑滑块、尖角保护、预览不改文档、生成路径与预览相同、撤销／重做、SVG 下载、关闭实时预览后的手工生成。
- 数学回归验证二次曲线精确升阶、三次路径差异、零强度折线、完整强度接缝、正反环、孔洞、项目往返和新增节点不改原曲线。
- 界面截图使用程序生成的圆环和矩形，不含客户图片。

## 发布检查

保留原有工作区持久化、对齐／吸附／同色选择和独立 PSD 解析检查，新增曲线浏览器检查。完整单元测试和全部 CI 门禁通过后才部署。具体结果以对应 Actions run 为准，本文不提前宣称部署成功。

## 限制

局部转角圆滑，不是全局误差约束拟合。可能增加节点；非常狭窄或自接近轮廓仍需人工确认。SVG 继续用三次 C 表达（包含精确升阶的二次曲线），尚不支持 Q/C 导出切换。没有增加原生 AI/CDR，也没有完成 Photoshop 实机验收。本地注入页面不是持久化或线上实测。
