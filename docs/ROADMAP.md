# 后续迭代

## 0.1.x：先让操作稳定

优先收集书法、印章、少色图案的可公开小样。每个缺陷补一个最小复现测试。补足 Windows Edge / Chrome、真实剪贴板、文件下载和 GitHub Pages 首次访问回归。完善多节点操作、选择手感、恢复草稿及大稿件性能保护。

## 0.2：成熟描摹与几何内核

在独立引擎接口后接入并比较 VTracer WASM。用同一批样稿比较节点数量、孔洞、笔画粗细及拟合误差。比较 Paper.js 或其他成熟几何内核，替代目前折线近似的预览布尔模块。验证许可、依赖固定版本及本地打包，不依赖运行时 CDN。

改进闭合修补、曲线小刀、多个封闭子区域识别、通用 SVG 安全导入；保留先前项目版本的迁移能力。

## 0.3：分层输出验证

PSD 独立验证：多个形状图层、矢量蒙版、缩略图/合成预览、透明背景和 Photoshop 可编辑性。不得把“PNG 分层”算作“矢量 PSD”。

AI / CDR 先在目标软件验证 SVG/PDF 的路径与尺寸交接；原生 AI / CDR 列为独立研发，不通过修改扩展名冒充。不依赖在线转换网站作为隐藏后端。

## 印刷用途单独验收

RGB 屏幕填色不等于专色。后续增加物理单位、尺寸/DPI 定义、色彩模型及专色元数据之前，不将当前版本称为印前生产软件。

## 迭代约定

主分支保持可构建、可测试；每次改动用提交/PR记录原因，并更新 CHANGELOG。每个几何缺陷加入数据测试，发布前验证撤销与保存重开。使用公开或获授权样稿，私人原图不提交到 GitHub。
