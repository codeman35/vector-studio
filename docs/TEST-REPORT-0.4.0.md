## 能力边界

- GitHub Actions 测试站点是本地 HTTP 源，不是 github.io 上的人工复测。
- 公共发布的 GitHub 登录/手工上传/Commit 流程需用户确认；测试不代用户登录、不提交个人文件，不宣称下载已经发布。
- 同源公开库支持跨浏览器读取静态快照，不是实时共同编辑，也不是同步用户的所有本地项目。
- 测试稿为代码绘制的圆环/矩形，无真实客户图片。

- PSD 未新增格式特性；未进行 Photoshop、Windows 系统剪贴板或移动端实机验收。
