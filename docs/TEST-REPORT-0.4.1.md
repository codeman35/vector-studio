# 0.4.1 节点内部框选修复

日期：2026-09-24。

## 行为

节点模式下，不命中节点或控制手柄时，无论鼠标按下位置在填色内部、轮廓外部或镂空内部，都能拖动框选当前编辑对象的节点。框内节点拖动中实时高亮；Shift 从原选择追加。框选不会移动图形、修改颜色或生成撤销记录，也不会把其他对象自动加入编辑目标。

单击镂空内部仍选中整圈内轮廓；拖动超过 3 屏幕像素才视作框选，避免把框选误当作整圈选择。按 Escape、指针取消或失去捕获时，恢复框选前的节点选择。点中节点/手柄的拖动、Ctrl 加点、Alt 删点和画布平移保持原逻辑。

- 修复后的 app.js 通过 node --check；使用原有构建依赖和更新后的应用代码、重新计算 CSP 的本地测试 HTML，通过 scripts/browser-node-marquee.py。
