- 本地工作区是由此前源包和已发布单文件重建的子集，拥有旧 16 项和本次新增 19 项，共 35 项测试，全部通过；不能把这个数目当作远程完整测试数。
- `scripts/browser-precision.py` 使用 `page.set_content(dist/index.html)`，多次通过；包含真实点击、拖动、键盘输入和下载，不是单纯脚本调用业务函数。
- 浏览器覆盖：六向对齐的代表操作、画板基准、间距／中心分布、群组整体保形、仅单击选择后的按钮状态、同色与右键选择、隐藏／锁定排除、端点／节点／关闭／Shift 吸附、缩放下屏幕距离、多个节点相对位置保持、Esc 取消与撤销、钢笔落点、Ctrl 加点／Alt 减点、SVG 和项目下载。
- 19 项新增单元测试覆盖实际三次曲线极值、六种对齐、分布首尾固定、空间不足无修改、嵌套群组与部分选中、手柄保持、计划原子性、同色选择、目标排除及多档缩放距离。
- 原本 0.2.0 的所有远程测试与工作区／PSD 部署门禁均保留；新增浏览器精确编辑测试也作为部署门禁。

## 边界与未验证项

- 本地浏览器访问本地 HTTP 开发服务器被运行环境拦截（ERR_BLOCKED_BY_ADMINISTRATOR）；本地测试没有覆盖真实网页来源下的 IndexedDB，也没有验证已部署网页。
- 仓库 Actions 中保留真实来源的 `browser-workspace.py` 和独立 PSD 格式检查；以这次具体运行结果为准，不提前声称通过。
- 浏览器注入回归没有额外承诺 Windows 实机、系统剪贴板权限、多浏览器或大规模性能；测试素材均为自行构造，不含用户图片。
- 对齐只平移锚点，不改变贝塞尔手柄；边界不包含描边。均匀分布至少三个单位，首尾不动。
- 吸附为径向 8 屏幕像素内的节点到节点定位，不吸附网格、路径中点或独立 X/Y 参考线，也不自动融合节点或连接路径。
- 按颜色选择为精确匹配而非近似色差选择；部分群组不会连带选中异色成员。
- 未改自动描摹引擎、切割近似算法、PSD 子集或原生 AI/CDR 输出。此前单文件 0.3.0 曲线实验稿不等于已合入主线的功能。
