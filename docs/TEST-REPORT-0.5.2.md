# 0.5.2 线段拖动不自动选中端点

2026-09-24。

## 修改范围

线段拖动只改变该段两个控制手柄，不改变节点选择。保留拖动前的空选择、单个端点、其他节点或多个节点；不强制选中两端，也不强制清空用户原来的选择。拖动手柄的临时显示与 selected 状态分离。松开和取消均恢复之前的节点选择。

## 本地验证

- 从主线 526da13768ce183d4e23a95787b8f5aa013652d0 的成功 Pages 构建恢复测试依赖，app.js 恢复前后 Git blob SHA 均为 73891b291d88c7d3d212929e5d6fb9f3f746dd31。只提交 app、版本、回归和文档，不覆盖未修改的依赖或远程旧测试。
- 在未改的 0.5.1 构建运行新增选择断言，可复现错误：单击线段就自动选中了两个节点。
- 修改后 npm run check、npm test、npm run build 通过。本地可用纯函数测试为 14 项子集，不冒充仓库全量。
- 扩充的 browser-curve-drag.py 在 Chromium 隔离 HTML 模式实际通过。涵盖线段点击/拖动/松开后无新增选择；六种先前选择；结束后只移动一个节点；点击、回原点、Escape、pointercancel、lostpointercapture、blur 保留先前多选。
- 同一脚本继续检查原有弧线光标、向内外拖动、固定锚点、相邻线段不变、内部/Shift 框选、Ctrl/Alt、手柄优先、镂空/开放/闭合段、撤销重做及 SVG/项目导出。
- 本地 HTTP 导航被环境以 ERR_BLOCKED_BY_ADMINISTRATOR 拦截，因此本地隔离页面通过不等于真实源存储或线上验证。
