## 算法边界

当前实现是连续点列的自适应数值拟合：切线约束三次最小二乘、弦长参数、有限 Newton 改进和最大误差点分割；二次最小二乘结果精确升阶。尖角分段，平滑三次分段共用切线。直线仍可用 L。

图像阈值、下采样、RDP 误差与曲线拟合误差是不同阶段。拟合滑块单位是采样像素，不能当成从原图到最终 SVG 的全局最大误差保证。曲线/轮廓相交检查基于数值采样，不是精确 CAD 拓扑证明。检测失败回退该组折线并提示；非常复杂输入仍需人工检查。

未改变现有布尔/刀切的折线近似，也未实现 Q/C 导出选择、原生 AI/CDR 或新的 PSD 生产兼容性。
