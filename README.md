# 线境 · Vector Studio

纯前端、开源、本地优先的图片描摹和 SVG 路径编辑器。当前主线 **0.3.1 预览版**，MIT 许可。

- 在线入口：https://codeman35.github.io/vector-studio/
- 源码仓库：https://github.com/codeman35/vector-studio
- 发布结果：https://github.com/codeman35/vector-studio/actions/workflows/pages.yml

有地址不等于新版本已上线。更新以对应 Actions 的 build/deploy 成功、页面左上角版本为准。刷新前请保存并下载项目备份。

## 0.3.1：贝塞尔选项在哪里

导入图片后，在右侧 **图片描摹 → 描摹模式下方 → 轮廓线条 · 贝塞尔 → 线条类型** 选择：

- 硬边折线：保留简化后的直线轮廓，默认选项。
- 二次贝塞尔（圆滑）：使用二次曲线圆滑局部转角，精确升阶为三次节点保存。
- 三次贝塞尔（圆滑）：使用三次曲线圆滑局部转角。

可拖动「圆滑程度」，或勾选「保留尖角」来对比效果。0% 保持折线；纯直线和受保护尖角可能没有变化。未导入图片时控件置灰；只有选择曲线后才启用圆滑参数。

勾选实时预览时，修改参数自动更新预览，不改现有图层；满意后点击「生成矢量轮廓」。已经生成的图形不会因切换选项自动变形，需要明确重新生成。重新生成会按「替换此前描摹对象」选项处理，请先备份已手工编辑的描摹对象。

这次修改已经接入源代码、Worker 和正式构建，不是之前那个未合入的 0.3.0 实验 HTML。保留 0.2.1 的项目库、群组、PSD 实验导出、对齐、吸附和同色选择。

**能力边界：**当前算法在像素边界提取和 RDP 简化后做局部圆滑，不是 VTracer 或带全局误差保证的高质量拟合器；可能增加节点。狭窄笔画、复杂自接近轮廓需人工检查。二次曲线是数学上等价升阶，不只是标签，但编辑器和 SVG 导出目前统一采用三次 C 命令（直线仍是 L），尚无 Q/C 导出切换。SVG 的坐标仍按现有精度输出。

## 主要工作流

粘贴／拖入／打开 PNG、JPEG、WebP、BMP → 参数实时预览 → 确认生成矢量轮廓 → 修节点、切割、合并、填色 → 保存项目／导出。

图片在浏览器本机处理，无图片上传接口、CDN、第三方统计或 API 密钥。GitHub Pages 仅分发静态网页程序，不承担图像计算。

## 对齐、吸附与同色选择

在右侧「图形属性」使用六向对齐：左、水平居中、右、顶、垂直居中、底。基准可选「所选整体边界」或「画板」。选择范围至少两个单位；画板对齐允许一个单位。

水平／垂直分布可选「边缘间距相等」和「中心距离相等」。至少选择三个单位，首尾不动；间距不足时拒绝操作，不强行制造负间距。

完整选中群组作为一个整体；只选择组内部分对象时不会拖入其他成员。对齐仅平移节点，保持曲线手柄和群组结构。边界采用三次贝塞尔实际路径极值，不含描边宽度。每次操作支持一次撤销。

节点拖动与钢笔落点在 **8 屏幕像素**内吸附，并显示十字和目标说明。可选所有节点，或仅开放路径端点；可整体关闭。正在拖动节点时、或钢笔落点时按住 Shift 暂时关闭吸附。Shift 开始单击节点仍用于原有多选。

被拖动节点、隐藏／锁定对象不作为目标。多节点保留彼此相对位置。吸附只改变位置，不自动连接、合并路径；需要连接时显式使用「连接端点」。当前不是网格吸附或单轴智能参考线。

选中一个对象，再点「相同填充色」或「相同描边色」；右键也有入口。颜色精确匹配，跳过隐藏／锁定对象，不连带选中群组中的其他颜色。多选参考对象须颜色一致；描边需实际存在。选择本身不修改文档，不增加撤销记录。

## 已有功能

- 黑白和少色像素轮廓描摹、阈值、去杂点、RDP 简化；180 ms 参数防抖，不承诺计算在 180 ms 内完成。
- 临时预览可切换原图叠加轮廓／矢量填色／原图，只有确认生成才写入项目。
- 节点和控制手柄、钢笔折线、矩形、椭圆、颜色及描边。
- 双击图形进入节点编辑；Ctrl／Command 点击曲线加点；Alt 点击节点删点。
- 小刀仅作用于鼠标按下到松开的有限线段，不延长。须贯穿区域才切成独立部分；轮廓剪断使用另一个工具。
- 合并、相减、交集、独立区域拆分；孔洞为真实 even-odd 透明区域。
- 图层形状缩略图、群组树、群组／解组、显隐、锁定、叠放、右键操作、撤销重做。
- 本浏览器项目库：保存、另存、搜索、切换、删除、下载备份；未保存时提供保存／放弃／取消；跨标签页 revision 防覆盖。

## 保存和输出

`.vstudio` 保存完整项目及参考图；版本 2 支持群组并可读取版本 1。Ctrl S 保存到本机浏览器项目库，「下载项目」用于独立备份或跨设备迁移。项目库不是云盘，换电脑／浏览器不会自动同步，清除站点数据会丢失本地记录。

SVG 导出真实路径、颜色、镂空及嵌套 g 群组，不嵌入原图。

PSD 仅为需主动确认的实验子集：RGB8、闭合纯色形状、无描边，写入 SoCo/vmsk/lsct 和预览；不把像素层当作矢量层。存在独立结构解析检查，但没有 Photoshop 实机验收。

**尚未支持：** 原生 AI/CDR、PDF、CMYK/专色、通用 SVG 导入、任意线围区填色、成熟全局误差控制的自动贝塞尔拟合、自由曲线刀切和离线重启缓存。

## 算法和预算

当前是原生 JavaScript + SVG + Web Worker，不是 Paper.js / VTracer 集成。描摹提取外轮廓而不是中心线。布尔与切割将曲线按局部 0.35 px 容差展开为折线，不代表全流程／印刷误差保证。

导入图像最大边 1800 px，描摹最大边 1024 px；最多 1500 对象、50000 节点；几何操作展开后最多 3500 边，描摹最多 150000 边界边。复杂输入会被拒绝；未经人工检查不要用于生产母版。

## 本机开发与测试

开发机使用 Node.js 22，无 npm 运行依赖；网站使用者不需要安装 Node 或任何后台。

```sh
npm start
npm run check
npm test
npm run build
```

根 `index.html` 是 ES 模块开发入口，需 HTTP 服务；`dist/index.html` 是构建生成的单文件，含本地 Worker 和重新计算的 CSP 哈希。长期修改源代码，不直接修改 dist。

```sh
python scripts/browser-smoke.py
python scripts/browser-interaction.py
python scripts/browser-workspace.py
python scripts/browser-precision.py
python scripts/browser-trace-curves.py
python scripts/verify-psd.py
```

浏览器测试需要 Playwright／Chromium，PSD 检查需要 psd-tools，均仅为开发测试依赖。默认注入页面的测试不能代替真实源 IndexedDB 测试。当前 CI 执行工作区持久化、精确编辑、贝塞尔控件及 Worker、独立 PSD 检查，通过才发布。细节见各版 `docs/TEST-REPORT*.md`。

模块：`src/app.js` 交互入口，`document.js` 模型／历史／导出，`geometry.js` 几何，`groups.js` 群组，`trace*.js` 描摹／预览／局部圆滑，`project-*.js` 项目库，`psd.js` 实验格式，`precision.js` 对齐／颜色／吸附纯函数，`precision-ui.js` 相应界面适配。
