# 线境 · Vector Studio

纯前端、MIT 开源、浏览器本机处理的图片描摹与矢量路径编辑器。当前 **v0.5.2 预览版**。

在线：https://codeman35.github.io/vector-studio/

发布以对应 Actions 的 build/deploy 成功和页面版本为准。更新前保存并下载项目备份；不要清除站点数据来刷新，否则本地项目可能丢失。

## 0.5.2：拖动线条不再自动选中端点

线段拖动与节点选择分开：悬停、点击、拖动及松开线段，都不会顺便选中两个端点。原来没有选中节点，结束后仍不选中；原来手动选择了节点，就保留原来的选择，不强制清空或替换。临时显示控制手柄不代表节点被选中。

拖完曲线再单独点击一个节点拖动，不会因为程序自动双选而把另一端一起带走。向内/向外拉弯、固定端点、框选、取消和一次撤销均保持。

## 0.5.1：弧线光标与固定端点拖动

双击图形进入节点编辑，将鼠标移到两个节点之间的线条上。出现弧线与双向箭头光标、蓝色线段高亮后，按住左键向外拉或向内推。两个端点不动，只调整本段的两个控制手柄；直线同样可以拉弯，不增加节点。

节点和控制手柄优先命中；远离轮廓线的内部/外部区域仍可框选。Shift 在非节点位置强制追加框选，Ctrl 点击曲线加点，Alt 点击节点删点。拖动超过 3 屏幕像素开始变形，单击不改几何。Escape 取消；松开后 Ctrl Z 一次撤销。拖回起点保持原几何。

相邻线段保持不变，因此交接处可能变尖，需要时再手动平滑。不是联动修改整条轮廓，也不会替换保存过的颜色。

## 0.5.0：连续曲线、红色默认填充、对象内编辑

默认「三次贝塞尔 · 保角平滑」。入口是顶部 **贝塞尔轮廓**，或右侧 **图片描摹 → 轮廓线条 · 贝塞尔**。导入图片后启用；选择二次/三次/折线，调整圆滑程度、曲线拟合容差与保留尖角，可实时预览。只有点击「生成矢量轮廓」才应用。

现在将连续点列拟合为较少的曲线段，不是给每个折线角加两个倒圆节点。直线保留，受保护尖角保留。预览显示拟合前后节点数量。容差单位为描摹采样像素，越小通常越贴轮廓、节点更多。三次曲线以共享切线连接平滑分段；二次曲线采用等价升阶保存，导出仍为 SVG L/C，不提供 Q/C 导出切换。

**颜色指图形填充，不是画布背景。**新建图形和黑白描摹默认红色 #e60012；叠加轮廓预览也改红。镂空透明、画板颜色不变。用户保存的颜色和少色描摹的实际颜色不被强制修改。

双击图形进入原画布节点编辑，双击空白退出。编辑时显示当前对象名称与退出按钮，保留修改及撤销记录。孔洞不是外部空白，双击孔洞不会误退出。从图形内外或孔洞内部拖动都可框选节点；点击节点/手柄则拖动它。Shift 追加框选，Ctrl 点击路径加点，Alt 点击节点删点。

已有项目不会自动重拟合或重染。对旧稿使用新描摹需要先备份，再重新生成；「替换此前描摹对象」可能覆盖手工修改的描摹结果。

## 项目与分享

**保存本地 / Ctrl S** 保存当前浏览器 IndexedDB，换电脑/浏览器不自动出现。「下载项目」提供含原图、图形及群组的 .vstudio 备份。项目库支持搜索、另存、切换、删除、缩略图及未保存提醒；跨标签 revision 防止旧版本覆盖。

**公开项目** 读取 GitHub 已发布的同源 JSON，其他人无需登录即可打开副本。公开操作是「公开项目 → 发布当前项目 → 确认 → 下载待发布 JSON → 在 GitHub 上传并 Commit」，测试/部署成功后才能分享。默认不含参考原图，不自动迁移私人历史，不在网页存储 Token，下载 JSON 不等于发布。公开后他人副本和 Git 历史可能保留。

公开文件位于 public-projects/，构建时验证并生成索引，不手改生成索引。只内置合成几何示例，没有未经授权的客户稿件。

## 编辑能力

图片粘贴/拖入/打开，黑白和少色描摹、实时预览；贝塞尔节点/手柄，钢笔、矩形、椭圆；有限线段刀切（不会沿延长线切割）、路径剪断、连接、闭合、布尔运算；填色与描边；图层缩略图、群组树、显隐、锁定、右键和撤销重做。

镂空可直接单击内部选中内圈，再 Delete 填实；或在「图形属性 → 轮廓/镂空编辑」选择子轮廓删除。删除其他轮廓不修改保留下来的贝塞尔坐标。

图形属性提供六向对齐，基准为选区或画板；水平/垂直均匀分布支持边缘间距或中心距离。完整群组整体移动。节点/端点吸附在 8 屏幕像素内，拖动中 Shift 暂停；吸附不自动连接。相同填充/描边色选择跳过隐藏/锁定对象，不选入组内其他颜色。

## 导出与限制

SVG 为真实路径、颜色、透明孔洞和嵌套群组，不含参考图片。.vstudio 为 version 2，可读取 version 1。

PSD 仍是主动确认后使用的 RGB8 纯色闭合无描边实验子集，写矢量蒙版/纯色层/群组和预览；独立结构检查不能代替 Photoshop 实机验收。

**尚未支持：**原生 AI/CDR、PDF、CMYK/专色、通用 SVG 导入、任意线围区填色、自由曲线刀切、匿名云保存及离线重启缓存。不改后缀冒充格式。

曲线拟合是数值近似，不等于 FontCreator 的同一算法或全局印刷精度保证。仍在 RDP 简化后拟合；非常低清晰度、细笔画、噪声和复杂自交需人工检查。检测到候选轮廓存在风险时回退折线，预览会提示。几何布尔/切割仍按局部 0.35 px 展平，因此切割结果可能需要重新修曲线。

导入最大边 1800 px，描摹最大边 1024 px，最多 1500 对象/50000 节点。不是 VTracer/Paper.js 集成，不上传原图计算，不使用 CDN、跟踪服务或 API 密钥。

## 开发与测试

开发使用 Node.js 22，无 npm 运行依赖。网站访问者无需安装环境。

```sh
npm start
npm run check
npm test
npm run build
python scripts/browser-workspace.py
python scripts/browser-precision.py
python scripts/browser-trace-curves.py
python scripts/browser-sharing.py
python scripts/browser-node-marquee.py
python scripts/browser-editor-quality.py
python scripts/browser-curve-drag.py
python scripts/verify-psd.py
```

Playwright/Chromium、psd-tools 仅为测试工具。根 index 为模块开发入口；dist/index.html 是固定模块图打包的单文件，包含 Worker 及重新计算的 CSP 哈希。长期修改 src，不直接改 dist。注入式浏览器测试不冒充同源 IndexedDB/网络验证。CI 保留持久化、分享、精确编辑、框选、曲线及 PSD 测试，通过后自动发布 main；PR 不部署。
