# 线境 · Vector Studio

纯前端开源图片描摹 / SVG 路径编辑器，**v0.4.0 预览版**，MIT 许可。

在线入口：https://codeman35.github.io/vector-studio/

公开几何示例：https://codeman35.github.io/vector-studio/?project=example-contours

新版本以 Actions 的 build/deploy 结果和页面左上角版本为准。刷新前保存并下载项目备份。没有服务器图像处理，没有 CDN 或网站内的 GitHub Token。

## 0.4.0 操作入口

### 二次 / 三次贝塞尔在哪里

顶部第二行新增 **贝塞尔轮廓** 按钮，直接进入右侧图片描摹的 **轮廓线条 · 贝塞尔** 区块。区块移到参考图片上方，直接显示 **硬边折线 / 二次贝塞尔 / 三次贝塞尔** 三个按钮，同时保留下拉框。

先导入图片，才启用按钮；点击选项并拖动圆滑程度会更新临时预览。满意后确认「生成矢量轮廓」才修改图层。重新描摹可能替换之前的描摹对象，手工修稿前后都应保存备份。

二次曲线数学上等价升阶为三次节点保存，SVG 目前统一用 L/C；不是 Q/C 导出格式选项。曲线算法仍是 RDP 后的局部圆滑，不是全局误差受控拟合，不保证低分辨率图能恢复真实笔触。

### 镂空与子轮廓删除

选择或节点工具下，单击没有被其他对象遮挡的镂空内部，会选中该内轮廓全部节点。按 **Delete** 删除这条内轮廓，原孔洞就会填实。**Ctrl Z** 一次撤销。

也可选中一个图形，在 **图形属性 → 轮廓 / 镂空编辑** 中选择「镂空内轮廓」再删除，适用于重叠对象或不易点选的小孔。删除外轮廓连同它的子轮廓移除；同一对象里的独立区域不受影响。全部轮廓被删后删除空对象。选中整圈和只选少量节点是不同操作。

删除时保留剩余节点的原有贝塞尔坐标和手柄，不将剩余曲线展开为折线。复杂重叠 / 自交路径的轮廓归属判断仍应人工核对。

### 更容易命中节点

节点可见框约 **10 × 10 屏幕像素**，附带 **22 × 22** 透明鼠标命中框，几何命中会优先选择近处节点。缩放后屏幕命中尺寸不变。控制手柄也扩大为直径 9 像素显示、20 像素命中。Ctrl 点击路径加点、Alt 点击节点删除、Alt 拖动手柄独立调整仍保留。

## 本地保存和公开项目：两个不同功能

**保存本地 / Ctrl S** 保存到此浏览器的 IndexedDB。换浏览器、换电脑不会自动出现；清除站点数据可能丢失。**下载项目** 保存 `.vstudio` 备份，包含参考图、图形和群组。

**公开项目** 读取 GitHub 已发布的公共 JSON，任何浏览器无需登录都能查看和打开副本。打开后修改的是本地副本，不自动覆盖公共原稿。公开库不会读取或迁移用户以前的浏览器项目。

### 发布自己的项目

1. 打开要发布的项目，点击顶部 **公开项目 → 发布当前项目**。
2. 检查公开范围并确认授权。默认不包含原始参考图片；图形、颜色、图层名称会公开。
3. 下载待发布 JSON，然后点击 **在 GitHub 上传**，选择刚下载的文件并 Commit changes 到 `main`。非维护者提交 PR，由维护者审核。
4. 等 Actions 测试和 Pages 部署成功，刷新公开列表。只有此时分享地址才可用。

**下载 JSON 不代表已经上传或发布。**网页不会暗中使用聊天连接的授权，也不要求粘贴密码或 Token。发布步骤需要在 GitHub 官方页面登录确认；当前没有匿名上传或一键云保存。

JSON 存放在 `public-projects/`，构建脚本验证格式后生成公开索引和缩略图。不要手工维护生成的 `index.json`。仅添加了自行绘制的测试几何示例，没有公开任何用户原图或私人项目。

公开后任何人可能下载副本，GitHub 提交历史也可能保留；删除当前文件不能保证历史和他人的副本全部消失。请勿发布客户未授权内容。

## 已有编辑能力

PNG/JPEG/WebP/BMP 输入与粘贴、黑白/少色描摹、实时预览、参数防抖、节点和手柄、钢笔/矩形/椭圆、有限线段刀切、路径剪断/连接、闭合、布尔合并/相减/交集、填色和描边、图层缩略图、嵌套群组/解组、上下文右键、撤销重做、本地项目切换提醒。

图形属性中支持六向对齐和水平/垂直分布（边缘间距或中心距离）。完整群组作为整体。节点/端点吸附为 8 屏幕像素，拖动中 Shift 暂停；只对位不自动连接。相同填充色/描边色选择为精确匹配，跳过隐藏/锁定对象，不选入组内其他颜色。

## 输出和限制

SVG 保留真实路径、颜色、even-odd 镂空和嵌套群组，不嵌入参考图片。`.vstudio` 为完整本地项目，version 2 可读取 version 1。

PSD 是主动确认后使用的实验子集：RGB8、闭合纯色、无描边，写入矢量蒙版/纯色层/群组和预览。已有独立格式解析检查，但未做 Photoshop 实机验收。

**未实现：** 原生 AI/CDR、PDF、CMYK/专色、通用 SVG 导入、成熟全局曲线拟合、任意线围区填色、自由曲线刀切和离线重启缓存。不能改文件后缀来冒充格式。

描摹不是 Paper.js / VTracer 集成。几何运算将曲线按局部 0.35 px 容差展开，非全链路印刷精度保证。输入最大边 1800 px，描摹最大边 1024 px；最多 1500 对象、50000 节点。未经人工检查不应用于生产母版。

## 开发、测试与发布

开发机 Node.js 22，无 npm 运行依赖。`npm run check && npm test && npm run build`。`npm start` 为本机开发静态服务，网站用户不需要安装任何运行环境。

`src/` 是源代码；`dist/index.html` 是含 Blob Worker 和 CSP 哈希的生成单文件。公开索引及数据在 `dist/public-projects/`，公开库功能需要 HTTP(S) 网站和对应静态文件，不是仅复制 HTML 就自带公共数据。

新增 `contours.js` / `contour-ui.js` 管理子轮廓，`public-projects.js` / `public-library.js` 管理公开快照和界面，`scripts/build-public.mjs` 校验和构建公开库。

CI 保留项目库存储、精确编辑、贝塞尔 Worker、独立 PSD 检查，并添加 `python scripts/browser-sharing.py`，覆盖同源 HTTP、两个独立浏览器上下文的公开项目读取、明确发布确认和未上传状态。`VS_INJECT=1` 仅供受限环境局部 UI 测试，不能冒充持久化或跨浏览器网络测试。

推送 `main` 自动检查/测试/构建/部署，PR 不部署。首次复制到新仓库需自行开启 Pages。操作规范见 `AGENTS.md`。

## 安全与许可

默认计算和本地项目不上传；只有用户主动在 GitHub 提交才公开。读取公开库使用同源 GET。不提交秘密，不执行导入脚本；CSP 和校验不等于完整安全审计。MIT 见 LICENSE，第三方素材授权由发布者确认。
