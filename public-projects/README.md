# 公开项目数据

本目录中的 JSON 会在构建时校验并复制到公开站点。任何人都可下载；不要提交客户未授权图案、私人资料或秘密。

在编辑器「公开项目 → 发布当前项目」确认公开范围并下载 JSON，再到 GitHub 上传到本目录、提交 main（外部贡献者提交 PR）。Actions 通过后才进入公开列表。不要把仅下载文件描述为已发布。

文件名必须是 `<id>.json`，ID 为小写字母、数字或连字符，最多 80 字符。格式由 `src/public-projects.js` 校验。`index.json` 与缩略图是构建生成的索引，不手工提交。每个项目最多 24 MB，当前公开列表最多 250 项。

默认不包含参考原图；勾选公开原图之前必须确认授权。Git 历史和他人下载可能保留旧副本，不能承诺删除当前文件后所有副本消失。

`example-contours.json` 是专门编写的几何测试示例，不含用户稿件。
